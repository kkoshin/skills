# 技术指标的实现与验证

所有指标都构建在同一层 K 线上：**仅交易日的日 K**（停市日判定与缓存见
`klines-and-sessions.md`）。两个指标共用 `trading_bars()`，口径不会分叉。

## KDJ(9, 3, 3)

```
RSV = (C - LLV(L, 9)) / (HHV(H, 9) - LLV(L, 9)) * 100      # 分母为 0 时取 50
K   = ((M1-1) * K_prev + RSV) / M1                          # K 初值 50
D   = ((M2-1) * D_prev + K)   / M2                          # D 初值 50
J   = 3K - 2D
```

前 9 根用不足 9 的窗口（与通达信 LLV/HHV 的行为一致）。K/D 初值 50 的残留为
`50 * (2/3)^k`，实测 20 根后仅 1.5e-2，可忽略。

### 验证

用闭式可验的构造，而非"看着像"：

| 用例 | 构造 | 期望 | 结果 |
|---|---|---|---|
| RSV 恒 100 | 收盘=最高、最低压低 | K₁=(2·50+100)/3=66.666667<br>D₁=(2·50+K₁)/3=55.555556 | 逐位吻合 |
| 收敛 | 同上 25 根 | K/D/J → 100 | 99.998 / 99.982 / 100.031 |
| RSV 恒 0 | 收盘=最低 | K₁=33.333333, D₁=44.444444 | 逐位吻合 |
| 边界 | 高==低 | RSV=50，K/D/J 保持 50 | ✅ |
| 恒等式 | 全样本 | J = 3K − 2D | ✅ |

## RSI(Wilder)

```
delta = C_t - C_{t-1};  gain = max(delta,0);  loss = max(-delta,0)
avg   = SMA(gain/loss, N)                        # 种子
avg   = (avg * (N-1) + x) / N                    # 其后 Wilder 平滑
RSI   = 100 - 100 / (1 + avgGain/avgLoss)        # avgLoss=0 → 100；全平 → 50
```

### 收敛慢是固有性质，必须报出来

Wilder 平滑等价于 `alpha = 1/N` 的 EMA，**种子权重为 `((N-1)/N)^k`**，衰减很慢：

| 周期 | 种子降到 5% 所需 K 线 |
|---|---|
| RSI6 | 24 |
| RSI12 | 48 |
| RSI14 | 56 |
| RSI24 | **96** |

而币安 TradFi 永续的历史很短（KOUSDT 仅 41 根日 K），所以 RSI12/24 常常还没收敛。

**不要把数值藏起来，也不要用「可用/不可用」的标签一笔带过** —— 报出 `seedInfluence`
这个连续量，让调用方自己判断能信几分。实测 KO 的 RSI24 种子占比 **81%**
（数值基本由种子决定），而 MUU 的 RSI12 只有 **6%**（已接近可用），两者的可信度
差一个量级，一个布尔值表达不了这个差别。

`seedInfluence = ((N-1)/N)^(bars - N - 1)`，JSON 里与 `value` 并列输出。

### 验证

| 用例 | 期望 | 结果 |
|---|---|---|
| 手工小样本 N=2, closes=[10,11,10,11] | r[2]=50, r[3]=75 | 逐位吻合 |
| 单调上涨 | 100 | ✅ |
| 单调下跌 | 0 | ✅ |
| 横盘不动 | 50 | ✅ |
| 200 组随机游走 × 3 周期 | 全部落在 [0,100] | ✅ |
| `_rsi_value` 对涨跌比单调 | 单调递增 | ✅ |

## 样本不足时的行为

| 情况 | 行为 |
|---|---|
| K 线数 < 20 | KDJ 打警告，K/D 仍在被初值牵引 |
| K 线数 ≤ RSI 周期 | RSI 显示 `-`，`seedInfluence: null` |
| 合约不存在 | `接口返回空响应（HTTP 200 无内容）` |
| 最后一根未收盘 | `lastBarClosed: false`，值仍会变到 UTC 日结束 |
